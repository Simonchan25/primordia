# PRIMORDIA · 人工生命实验室

### ▶ [**在线体验**](https://simonchan25.github.io/primordia/)（公开后可用） · [English README](README.md)

> 成千上万个粒子，几条简单规则。没有人设计涌现出的生命。

**PRIMORDIA** 是一个完全运行在浏览器里、单文件、零依赖的[「人工生命」](https://zh.wikipedia.org/wiki/人工生命)实验室。每一颗有颜色的粒子，只是被其他每种颜色吸引或排斥——**仅凭这一条规则**，就足以长出细胞、细胞膜、捕食者、会游动的生物，以及整个不断变化的生态。它是对科学与 AI 中最深刻的一个观念的、亲手可玩的演示：**复杂的、像生命一样的行为，可以从简单的局部相互作用中涌现，而无需任何全局蓝图。**

> 📖 **它为什么存在？目标是做一个"真正的生命"吗？** 请读[**《愿景与宣言》**](VISION.md)（中英双语）。一句话版本:不是——PRIMORDIA 是生命的「自组织」那一半，被做成让你无法移开眼睛的样子；诚实的目标是让"涌现"变得**可感**，并去追那更难的、至今无人解决的另一半(遗传、选择、开放式演化)。

**打开它，按下「开始」,一段电影般的导览旅程会自动播放** —— 低沉平静的**语音旁白**(由 [ElevenLabs](https://elevenlabs.io) 预先渲染;音频缺失时实时回退到浏览器自带语音)配上**实时生成的配乐**(Web Audio 即时合成),配以屏幕字幕,带你穿过*真实运行*的模拟:从"除了盲目规则一无所有"→ 自组织的细胞 → 演化出觅食行为的生物 → 一种生命分化为两种 → 直到生命、心智、以及"你"究竟从何而来。双语、可跳过、点标题可重播。

它内置**两套可互换的引擎**:

- **WebGPU 计算引擎** —— 整个模拟跑在 GPU 上,用计算着色器做*空间哈希*,可轻松处理**数万(最高约 20 万)粒子 @ 60fps**,带 HDR 渲染与多趟泛光(bloom)。
- **WebGL2 + CPU 引擎** —— 自动回退方案(也可用 `?cpu` 强制)。它共享*同一套* HDR → bloom → ACES 色调映射管线,所以两套引擎画面完全一致。哪儿都能跑。

界面**完全双语(English / 简体中文)**、**支持键盘与读屏器**(可聚焦的 ARIA 交互矩阵、带标签的控件、`prefers-reduced-motion`)、并且**对触摸友好**(捏合缩放、双指平移、手机上的吸引/排斥切换钮)。

## 两个实验室

PRIMORDIA 是一个有两个实验的*实验室*,在面板顶部切换:

- **🌌 原汤** —— 粒子生命世界:纯粹的**自组织**。局部吸引/排斥规则 → 涌现出细胞、细胞膜、捕食者。生命的*第一味*原料。
- **🧬 创世** —— 一个**开放式演化实验室**。成百上千个生物,每个都带着一段可遗传的基因组,编码一颗*拓扑会自己进化*的 NEAT 式神经网络大脑(变异会增加神经元和连接)以及身体特征;它们觅食、带变异地繁殖、然后死亡。**自然选择是涌现的——没有外加任何适应度函数。** 一套"植物→食草者→捕食者"的营养结构(小的青色食草者吃植物,大的品红色捕食者吃食草者,**世界铺满整个屏幕**)制造**红皇后军备竞赛**,而一项按连接计的代谢成本让大脑保持*自适应*而非虚胖。一条实时的**「发现的心跳」**(金色曲线)在世界每造出一个从未出现过的形态时跳动一下——这是被做成可观看的 Bedau–Packard 新奇度信号;角落读数 `形态 N +k`(累计发现 · 实时速率)。24 万步运行的结论:**倾向于开放式**——新奇度始终没有归零——尽管*无界*的开放式演化仍无人解决(见 [VISION.md](VISION.md))。拖动**「世界大小 · 隔离」**滑块加入空间结构,看心跳跳得更快——新奇度在某个中等世界尺寸达到峰值,这是一个被测量出来的*开放性的空间甜点*。生命的*第二味*原料——遗传 + 选择——以及对它最难前沿的一次真实推进。

「创世」是**经过验证、而非空口而谈的**——四个可在终端里运行的无头脚本(`node genesis_*.mjs`):
- [`genesis_core.mjs`](genesis_core.mjs):觅食对齐度(朝向 vs 朝最近食物的方向)在约 20 代内从 ~0(随机大脑)演化到 ~0.25–0.30,种群自我维持。
- [`genesis_open.mjs`](genesis_open.mjs):加入两种食物 + 可遗传的*食性*基因后,频率依赖的歧化选择让种群在 6 万步内**自发分裂成两个共存物种并保持分裂**——稳定多态(多样性*被维持*而非坍缩为单一栽培)。
- [`genesis_oee.mjs`](genesis_oee.mjs):开放性探针 —— NEAT 式可进化大脑 + 捕食者-猎物**协同演化** + 按连接的**复杂度成本**,用 **Bedau–Packard 演化活动度统计**在 24 万步上测量。脑复杂度在成本压力下从 ~6 升到 **60–70 条连接**(自适应,不是虚胖);捕食者比例*来回振荡*(军备竞赛永不落幕);新表现型类别的发现速率**始终没有归零**——**倾向于开放式**演化的严格特征。
- [`genesis_spat.mjs`](genesis_spat.mjs):**空间隔离**探针 —— 地理能否打破谱系固定?答案是**非单调**的:表现型新奇度在约 **1.8×** 世界尺寸*达到峰值*,在 2.6–3.4× 时随大种群收敛而*崩塌*;然而*血缘*多样性随空间持续增多(3.4× 可维持多达 **4 个共存谱系**)——揭示了**表现型新奇度与血缘多样性是两条在不同尺度达到峰值的不同的轴**(空间买来的是*共存*,不一定是*创造力*)。

## 运行

单个 HTML 文件,**零依赖、无需构建**。

- **最简单:** 双击 `index.html`。
- **或起一个服务:**
  ```bash
  python3 -m http.server 4321 --directory .
  # 打开 http://localhost:4321
  ```
- 用 `index.html?cpu` 强制使用 CPU/WebGL2 引擎。

WebGPU 需要 Chrome/Edge(稳定版)、Safari 18+、或开启了 WebGPU 的 Firefox;其余浏览器自动使用 WebGL2 引擎。当前引擎显示在左下角。

## 原理

每颗粒子有位置、速度和一个**物种**(颜色)。每一步,对每对在作用半径 `rmax` 内的邻近粒子,沿连线施加一个力:

```
        ┌  r/β − 1                                 当 r < β    (普适的短程排斥)
F(r) =  ┤  a · (1 − |2r − 1 − β| / (1 − β))        当 β ≤ r < 1 (来自矩阵的吸引/排斥)
        └  0                                        当 r ≥ 1
```

其中 `r` 是归一化到 `[0,1]` 的距离,`β` 是排斥区比例,`a` 是**交互矩阵**里"本物种对对方物种的感受"。矩阵是**非对称**的——红色可以追绿色,而绿色逃离红色——这打破了牛顿第三定律,也正是运动永不落入无聊平衡的原因。其余的一切——细胞、捕食者、薄膜——都是*涌现*出来的。

对*观感*影响最大的单一参数是**密度**(`粒子数 × 半径²`):低密度长出大而分离、发光的群落;高密度长出致密、流动的活体组织。

### 工程笔记

- **GPU 空间哈希(WebGPU)。** 空间是一个环面(toroidal),被划分成网格。每帧跑三趟计算:清空每格计数 → 用原子操作把每颗粒子装进定容量桶 → 一趟力+积分,只读取相邻 3×3 格。位置/速度缓冲乒乓交换以保证读取一致。任何东西都不回读到 CPU,所以能扩展到约 20 万粒子。
- **CPU 空间哈希(回退)。** 用同样的邻域思想,在类型化数组里做 O(n) 计数排序空间哈希——单核上几千粒子 @ 60fps。
- **HDR 渲染 + 泛光。** 粒子作为柔和的加性辉光绘入 16 位浮点缓冲;一趟亮度提取 + 可分离高斯模糊产生泛光;ACES 电影级色调映射合成到屏幕,致密的核心平滑地泛白而非硬截断。拖尾来自每帧带着轻微淡出的反馈。**两套引擎共享这一套观感。**
- **自适应画质。** 一个帧率看门狗会在机器跟不上时悄悄降低粒子数。
- **无障碍。** 尊重 `prefers-reduced-motion`;交互矩阵可键盘操作并带 ARIA;图标按钮有标签;焦点可见。
- **双语。** 一个小巧的 `data-i18n` + `t(key)` 层;语言自动从浏览器探测、存入 `localStorage`、并在切换时重建动态界面。
- **电影级旁白。** 旅程播放预先渲染的 ElevenLabs 英文旁白(`narration/chN-en.mp3`),播放时压低配乐,音频缺失则回退到浏览器 `speechSynthesis`。开场可选 **English / 中文字幕**——*字幕*切换语言,而旁白始终是英语男声。重新生成:`ELEVENLABS_API_KEY=… LANGS=en VOICE_ID=<id> SPEED=0.84 node tools/gen-narration.mjs` —— key 只从环境变量读取,绝不写入磁盘。
- 在控制台里把玩 `window.__P`(`.S` = 实时设置,`.GPU`、`.Sim`、`.G`)。
